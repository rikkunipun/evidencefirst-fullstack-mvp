# EvidenceFirst final submission checklist

Submit as **Solo**.

## Four required links

1. **Live Project Link**  
   https://evidencefirst-fullstack-mvp.vercel.app

2. **GitHub repo / JSON workflow Link**  
   https://github.com/rikkunipun/evidencefirst-fullstack-mvp

3. **Demo Video Link**  
   Record the four-minute walkthrough in `docs/demo-script.md`, upload it to Google Drive or YouTube, set it to anyone-with-the-link viewer, and paste the public URL here before submitting.

4. **Case Study Link**  
   https://docs.google.com/document/d/1T-gmO0Uq-E-CkZgGSCVrf-qOEwPeI26gsr4OHdSv4_0/edit

## Final checks before pressing Submit

- Open each link in an incognito window.
- Confirm the GitHub repository shows the full README on `main`.
- Confirm the case study and video do not request access.
- Use the submitted name and email exactly as registered with the course.
- Select **Solo**.
- Do not claim persuasion efficacy from synthetic QA sessions.
- Press Submit only after saving a screenshot of every completed field.
